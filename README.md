# 飛吧！航空大亨

**麥麥的遊戲工廠 出品**

🎮 **開始遊玩：https://s841148.github.io/fly-airline/**

從台北桃園機場出發，經營你自己的航空公司：真實世界地圖與航線、商務艙和經濟艙定價、
向飛機製造商殺價、管理機師和空服員，目標是成為台灣第一大航空公司。

### 四個玩法
- **航空大亨**：成立自己的航空公司，經營到台灣第一。
- **鯨魚機長**：當鯨魚航空的飛行員，從家裡換制服出門、搭機組巴士、到報到中心開會簽放行、繞飛機外部檢查，再爬上登機梯進駕駛艙，親手從起飛飛到降落，累積飛行時數升官。遇到危險時副機長會接手救機，也可以隨時把操控交給副機長。
- **機場航警**：安檢 X 光抓違禁品、幫助迷路旅客、追搶劫犯、帶警犬找可疑行李。
- **空中安全官**：在客艙裡安撫吵鬧旅客、處理廁所冒煙、檢查可疑行李、幫生病旅客找醫生。

### 遊戲內容
- 51 個真實城市、大圓航線、照班表起降的即時地圖
- 可開設高雄、台中、松山、曼谷、東京基地
- 12 種機型：A321neo、737-800、767-300ER、A330-900neo、787-8／-9／-10、777-200ER、747-400、A350-900／-1000、777F 貨機
- 經濟艙、豪華經濟艙、商務艙分開訂價，每架飛機的客艙可自己設計
- 設計公司塗裝，地圖上的飛機會換成你的顏色
- 向飛機製造商、租賃公司殺價
- 加入航空聯盟、和外國航空公司代碼共享
- 第一人稱開飛機：坐進駕駛艙全程飛完（起飛、爬升、巡航可快轉、下降、進場、降落），有簡單和真實兩種模式
- 和塔台用無線電對話（在 Claude 裡打開時是 AI 塔台）
- 第一人稱 3D 機場：報到 → 安檢 → 出境 → 走空橋登機，還有美食街、兒童遊戲區、二樓入境大廳、頂樓觀景台、紀念章和小任務
- 開飛機或逛機場的時候，公司經營會自動暫停
- 會隨時間變化的日夜地圖、尾跡雲、颱風旋渦；營收圖表與航線獲利排行

### 怎麼玩
- 直接在瀏覽器裡玩，電腦和手機都可以。
- 遊戲進度存在你自己的瀏覽器裡；換電腦時，可以用遊戲裡的「匯出存檔檔案」把進度帶走。
- 匯出的存檔檔案只是你的遊戲進度，不是遊戲本身。
